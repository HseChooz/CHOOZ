# CHOOZ

CHOOZ – мобильное приложение-помощник в подборе подарков. Продукт объединяет
- [x] вишлист
- [x] календарь событий
- [ ] подборки подарков (в разработке)
- [ ] быстрые заметки
- [ ] анкету пользователя, на основе которой формируются подборки
- [ ] стену с подарками-советами друзей

## Ценность продукта

Приложение помогает организовать информацию и идеи подарков в одном месте. Оно решает проблему хаотичных заметок, забытых событий и неудобного обмена идеями между пользователями.

Подготовка подарка в CHOOZ разделена на три этапа:
1. Вспомнить о событии.
2. Придумать идею подарка.
3. Найти объект, который подходит по критериям.
