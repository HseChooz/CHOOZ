# Стек проекта CHOOZ

## Backend

- Python 3.12
- Django 6
- GraphQL на `strawberry-graphql` и `strawberry-graphql-django`
- Django REST Framework
- JWT-аутентификация через `djangorestframework-simplejwt`
- PostgreSQL через `psycopg`
- S3-совместимое файловое хранилище / MinIO через `boto3`
- Gunicorn и Uvicorn
- Docker Compose для локального, stage и production-окружений
- `pytest`, `pytest-django`, `ruff`, `bandit`, `pre-commit` для тестирования и качества кода

## iOS

- Swift 6
- SwiftUI
- UIKit для навигации и контейнеров
- Tuist
- Apollo iOS для GraphQL-клиента и codegen
- Yandex Login SDK
- Google Sign-In
- AppMetrica
- iOS 17+
