# Контекст проекта CHOOZ

## Что делает продукт

CHOOZ — мобильное приложение-помощник в подборе подарков. Оно закрывает основной пользовательский сценарий вокруг подарков:

1. не забыть о важном событии;
2. собрать идеи подарков для себя или близких;
3. вернуться к этим идеям в нужный момент;
4. делиться вишлистом и смотреть вишлисты других пользователей.

## Что реально есть в текущем приложении

По текущему состоянию репозитория продукт уже покрывает следующие сценарии:

- onboarding при первом запуске;
- авторизация через Apple и Яндекс;
- личный вишлист с названием, описанием, ссылкой, ценой, валютой и изображением;
- календарь событий с датой, описанием, ссылкой, напоминаниями и ежегодным повтором;
- профиль пользователя и настройки;
- удаление аккаунта из приложения;
- просмотр публичного вишлиста другого пользователя через social profile и deep link вида `chooz://profile/:userId`.

## Что находится в развитии

В репозитории уже появился отдельный v2-домен для подборок подарков:

- на backend есть модели `Collection` и `CollectionItem`;
- GraphQL уже отдаёт главную страницу подборок и детали подборки;
- элементы подборок можно добавлять в личный вишлист и убирать из него;
- для подборок есть отдельные тесты и seed-данные.

При этом основной мобильный клиент по-прежнему сосредоточен на сценариях авторизации, вишлиста, календаря, профиля и social profile. Подборки уже активно развиваются на backend-уровне и выглядят как ближайшее направление продуктовой интеграции.

## Ценность продукта

CHOOZ сводит в одном месте то, что обычно распадается по заметкам, чатам и сохранённым ссылкам:

- идеи подарков;
- список желаемого;
- события и напоминания;
- обмен вишлистами между людьми.

За счёт этого приложение уменьшает хаос в подготовке подарков и делает путь от идеи до выбора заметно короче.

## Текущий этап

Проект уже вышел за рамки базового MVP и находится в фазе развития второй версии продукта. Практически это означает:

- core-сценарии мобильного приложения уже собраны и поддерживаются;
- backend постепенно расширяется новыми доменами;
- текущий самый заметный v2-фокус в кодовой базе — подборки подарков.
