# Контекст проекта CHOOZ

## Что делает продукт

CHOOZ — мобильное iOS приложение-помощник в подборе подарков. Продукт закрывает полный сценарий подготовки подарка и помогает пользователю:

1. не забыть о важном событии;
2. собрать идеи подарков для себя или близких;
3. вернуться к этим идеям в нужный момент;
4. делиться вишлистом и смотреть вишлисты других пользователей.

## Что реально есть в текущем приложении

По текущему состоянию репозитория продукт уже покрывает следующие сценарии:

- onboarding при первом запуске;
- авторизация через Apple и Яндекс;
- личный вишлист с названием, описанием, ссылкой, ценой, валютой и изображением;
- календарь событий с датой, описанием, ссылкой, напоминаниями и ежегодным повтором;
- профиль пользователя и настройки;
- удаление аккаунта из приложения;
- просмотр публичного вишлиста другого пользователя через social profile и deep link вида `chooz://profile/:userId`.

## Что находится в развитии

В репозитории уже появились backend-домены второй версии продукта:

- заметки уже реализованы на backend как отдельный домен с CRUD-операциями, избранным и автоматическим извлечением ссылки из текста;
- на backend есть модели `Collection` и `CollectionItem`;
- GraphQL уже отдаёт главную страницу подборок с поиском и детали подборки с поиском и фильтрацией по тегам;
- элементы подборок можно добавлять в личный вишлист и убирать из него;
- для подборок есть отдельные тесты, seed-данные и hardcoded-ассеты для обложек и карточек элементов.

При этом основной мобильный клиент по-прежнему сосредоточен на сценариях авторизации, вишлиста, календаря, профиля и social profile. И заметки, и подборки уже продвинуты на backend-уровне, но полноценного клиентского UI под них в текущем iOS-коде ещё нет.

## Ценность продукта

CHOOZ сводит в одном месте то, что обычно распадается по заметкам, чатам и сохранённым ссылкам:

### MVP:
- [x] Регистрация и вход через Яндекс
- [x] Заполнение собственного вишлиста
- [x] Календарь с напоминаниями о ближайших праздниках и событиях

### v2:
- [ ] Подборки подарков (в разработке)
- [x] Быстрые заметки на backend
- [ ] Анкета пользователя

MVP завершён. Сейчас команда работает над второй версией продукта.
Сейчас основной фокус продуктовой интеграции — подборки подарков, при том что backend для заметок уже тоже присутствует в кодовой базе.
