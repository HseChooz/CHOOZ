# Контекст проекта CHOOZ

## Что мы делаем

CHOOZ — мобильное приложение-помощник в подборе подарков. Продукт закрывает полный сценарий подготовки подарка и помогает пользователю:

1. вспомнить о событии;
2. придумать идею подарка;
3. выбрать объект, который лучше всего подходит по критериям.

## Основные функции продукта

- вишлист;
- календарь событий;
- быстрые заметки;
- стена с подарками-советами друзей;
- анкета пользователя;
- подборки подарков на основе анкеты.

## Ценность продукта

Приложение помогает хранить в одном месте информацию и идеи, связанные с подарками. Оно решает проблему хаотичных заметок, забытых событий и неудобного обмена идеями между пользователями.

## Что уже готово в MVP

- регистрация и вход через Яндекс;
- заполнение собственного вишлиста;
- календарь с ближайшими событиями и числом дней до них;
- сценарий, в котором пользователь сам постепенно наполняет календарь в процессе использования приложения.
